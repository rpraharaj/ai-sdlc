# Commit

Create one honest commit from what is actually in the tree. Do not push unless asked.

## Is this the right skill?

| Signal | Do this instead |
| --- | --- |
| Open a PR | `commit` first if needed, then `open-pr` |
| Undo | `revert-change` |
| Not a git repo | stop |

## Required inputs

- A non-empty diff that belongs to the request
- `git`

## Human decisions (do not invent)

- Commit everything when the tree mixes unrelated changes (do not silently bundle)
- `--no-verify` (only if they explicitly asked)
- Amend (only if they asked and the commit is yours and not on a shared remote)

## Procedure

1. Inspect: `git status`, `git diff`, `git diff --cached`, `git log -8 --oneline`.
2. Load `engineering-bar` Secret files. Any match → **stop**.
3. Stage only files that belong to the request. Do not `git add .` unless they asked to commit all remaining changes and the secret check passed.
4. Message matches `git log` style. Subject = what changed and why from the **diff**. No invented files. Do not mention agents or “generated by.”
5. Non-interactive commit. If hooks fail, fix the cause.

## Output

- Path: the new commit
- Template: [references/commit-report.md](references/commit-report.md)

## Quality bar

- [ ] Secrets absent
- [ ] Unrelated files left unstaged and listed
- [ ] Did not push unless asked

## Done

Fill the report. If they also asked for a PR, `open-pr`.
